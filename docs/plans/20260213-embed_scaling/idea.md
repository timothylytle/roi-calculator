# Embedd scaling
Using the embed function for embedding the calculators in other website produceses a fixed iframe like this

```
<iframe src="https://example.com" width="800" height="600"></iframe>
```

This makes it unfriendly for scaling to mobile,  I would the make this more dynamic maybe with responsive CSS.


I would like this to be definable in the embed menu, a toggle to make it dynamic, and be able to define the size when static values are prefered
